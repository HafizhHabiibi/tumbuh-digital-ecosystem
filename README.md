# Project PUI - Sistem Posyandu Digital

## Struktur Project
- `backend-express/` — REST API dengan Express.js
- `dashboard-vue/` — Dashboard web untuk Kader & Puskesmas
- `flutter-app/` — Aplikasi mobile untuk Orang Tua

## Tech Stack
- Backend: Express.js, MySQL
- Web: Vue.js
- Mobile: Flutter

## Fitur Utama
- Monitoring tumbuh kembang balita
- Deteksi risiko stunting dengan metode SAW
- Rekomendasi berbasis AI (LLM)
